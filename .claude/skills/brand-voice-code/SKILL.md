# Brand voice: Angular Agentic Software Engineering

The reader is an experienced Angular developer who has shipped applications and is here for
Angular 22 and for working with agents. They do not need to be sold the topic and they notice
padding immediately.

Rules live in [references/rules.md](references/rules.md). Read that file before editing prose.

## Fastest check

Read the first sentence of any section. If it says why the topic matters rather than what the
thing does, rewrite it. The course earns attention with specifics, never with enthusiasm.
