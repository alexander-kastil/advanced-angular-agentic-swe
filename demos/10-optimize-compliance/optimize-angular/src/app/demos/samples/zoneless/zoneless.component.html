Zoneless Change Detection

Without zone.js nothing monkey-patches the browser. Angular no longer finds out that something happened; it has to be told. A signal write tells it, a compiled template listener tells it, and markForCheck() tells it. A bare setTimeout tells it nothing.

1. Signal written from a timer

{{ signalTick() }}

The timer writes a signal the template reads, so the write itself schedules the refresh.

2. Plain field written from a timer

{{ plainTick }}

The field really does change after 600ms, but the screen keeps the old number. Watch it without clicking anything: any button you press marks this view dirty and hides the effect.

3. Plain field plus markForCheck()

{{ plainTick }}

Same write, followed by ChangeDetectorRef.markForCheck(). The screen catches up.

4. Application stability

{{ stability() }}

PendingTasks.add() is how you tell a zoneless app that async work is in flight. Server rendering, whenStable() and ApplicationRef.isStable all wait on it. This button registers a task, releases it after 1.5 seconds, and reports when whenStable() actually resolved.

Application render passes counted by afterEveryRender since the counter was reset: {{ renders }}. The whole page is one application, so the markdown pane on the right counts too, and the number you see is the count as of the previous refresh.
