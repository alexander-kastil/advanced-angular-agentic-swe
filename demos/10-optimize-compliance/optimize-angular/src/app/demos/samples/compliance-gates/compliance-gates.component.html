Gate the Pull Request

A performance rule nobody enforces is a preference. Four checks turn the rules in this module into merge conditions: the build budget, the template accessibility lint, an axe scan of the running app, and a Lighthouse CI run against the built dist/. Each one exits non-zero, so the workflow fails and the pull request cannot be merged.

Where this module stops

Module 09 gates the local build: everything below runs on a runner, against source and against dist/, before anything is deployed. Module 12 measures Core Web Vitals after deploy, against a live origin with real DNS and TLS. Same metrics, different question: here you ask whether the artifact is allowed to ship, there you ask what the artifact does in the world.

The workflow

The runnable file lives at .github/workflows/compliance-gate.yml in the module folder. Copy it to the repository root .github/workflows/ to activate it: GitHub only executes workflows found at the repository root, which is why it ships here as a reviewable artifact rather than a live check on this teaching repository. 

jobs:
  compliance-gate:
    steps:
      - run: npm ci
      - run: npm run lint                # template accessibility rules
      - run: npm run build               # budgets, exits 1 over maximumError
      - run: npx playwright test         # axe-core against the running app
      - run: npx --yes @lhci/cli@0.15.x autorun   # asserts against dist/
  • Assert on a floor, never on a delta. A gate that compares against the previous run ratchets down quietly as the branch gets slower.
  • Keep maximumWarning below maximumError so the number is visible in review long before it blocks anyone.
  • Run the axe scan against the built app on a static server, not the dev server. The dev server injects code your users never receive.
  • Upload the Lighthouse report and the Playwright trace as artifacts. A failing gate that shows no evidence gets disabled within a month.
  • Every gate here is deterministic on a runner. Field data belongs to module 12, and mixing the two makes a flaky check.
