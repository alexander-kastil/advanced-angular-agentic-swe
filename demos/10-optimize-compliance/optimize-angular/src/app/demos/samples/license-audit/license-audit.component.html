Audit Dependencies and Licenses

Shipping a bundle means shipping other people's code. The Cyber Resilience Act and most enterprise procurement rules expect you to know what is in it, under which licence, and with which known vulnerabilities.

Build output

extractLicenses is on by default in the production configuration, so every build writes dist/optimize-angular/3rdpartylicenses.txt. That file is the attribution notice you are obliged to make available.
