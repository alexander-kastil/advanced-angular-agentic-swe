Form Model vs Domain Model

  • The form model uses plain strings and numbers, never null or undefined
  • Date | null is the exception, because <input type="date"> needs it
  • An optional domain property (microchipId?) becomes a required empty string in the form model
  • applyWhenValue() guards validators so they only run once a value is present
