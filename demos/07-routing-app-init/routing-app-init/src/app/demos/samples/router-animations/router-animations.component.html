animate.enter and animate.leave

Angular 22 animates entering and leaving elements with plain CSS. No @angular/animations package, no trigger metadata: the element names a class and Angular waits for the animation to finish before removing it from the DOM.

Route transitions

Navigation between routes is animated by withViewTransitions() in app.config.ts, which hands the swap to the browser's native View Transitions API. The styling lives in src/theme/view-transition.scss.
