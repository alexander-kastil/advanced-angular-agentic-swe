Two lifetimes, one decorator

@Service() replaces @Injectable({ providedIn: 'root' }). Passing { autoProvided: false } keeps the class out of the root injector so that a route can own it through its own providers array.

@Service() @Service({ autoProvided: false })
Instance #{{ appWide.instanceId }} #{{ routeScoped.instanceId }}
Notes kept {{ appWide.count() }} {{ routeScoped.count() }}

Add a few notes, then leave the route and come back. The root instance keeps its number and its notes; the route-scoped one is destroyed with the route injector and starts over.
