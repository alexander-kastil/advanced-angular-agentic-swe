Firebase Authentication is an identity provider you can stand up in five minutes: email and password, Google, GitHub and others behind one SDK. The client signs in with the modular firebase/auth API and gets a Firebase ID token, a JWT issued by https://securetoken.google.com/<project-id> with the project id as audience. The API validates exactly those two claims.
