MSAL puts the OAuth client in the browser. Easy Auth, the built-in authentication of Azure App Service and Azure Container Apps, puts it in a sidecar in front of your container: the sidecar runs the flow, keeps the tokens server side, gives the browser a session cookie and forwards the identity to your code as request headers.

Decode X-MS-CLIENT-PRINCIPAL

The sidecar adds this header to every authenticated request: base64 JSON with the claims and the claim types that carry name and role. Clients cannot set it; the platform strips it from incoming traffic.
