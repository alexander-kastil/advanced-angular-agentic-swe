A single-page app is a public client: it cannot keep a secret, so it proves it is the same app that started the flow with PKCE. The values below are generated in this browser with crypto.getRandomValues() and crypto.subtle.digest('SHA-256'), the same primitives MSAL uses. 

code_verifier  {{ verifier() }}
code_challenge {{ challenge() }}
state          {{ state() }}
nonce          {{ nonce() }}
The verifier stays in the browser; only its hash travels in the redirect.

1. Redirect the user to /authorize

2. Redeem the code at /token

No client_secret: Entra ID rejects client credentials on any request that carries an Origin header. The verifier is what proves possession.
