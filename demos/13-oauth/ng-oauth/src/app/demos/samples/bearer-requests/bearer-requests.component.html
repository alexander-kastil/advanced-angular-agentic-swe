Every protected call ends as one HTTP header: Authorization: Bearer <token>. This route has its own HttpClient whose backend is an in-page echo server for https://api.ng-oauth.demo. It answers 401 without the header and echoes back everything it received with it.

Writing the header in every service call is the version that leaks: the first developer who forgets it ships a 401, and the first who copies it to a third-party URL ships your token. The next demo moves it into an interceptor.
