Why this matters for SSR

The child reads its params synchronously during the first render pass, so the server produces the finished markup in one go. An ActivatedRoute subscription resolves a tick later, which on the server means the first pass renders an empty shell.

Route params, query params and static data all bind by name. A name with no matching param stays at its declared default, which is why highlight reads not set until the query param is present.
