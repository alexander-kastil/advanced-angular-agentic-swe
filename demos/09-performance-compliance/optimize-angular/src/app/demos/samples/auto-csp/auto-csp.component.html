Harden with Strict CSP

A Content Security Policy is the last line of defence against injected script. The Angular application builder can generate a hash-based strict policy for you and inline it into index.html at build time.

Enable it in angular.json

"architect": {
  "build": {
    "options": {
      "security": {
        "autoCsp": true
      }
    }
  }
}

autoCsp is off by default while it is in preview. Set { "unsafeEval": true } only if a dependency genuinely needs eval, and treat that as a bug to remove.
