Box Stack

An Angular app, built to static files, that proves a container reached the box.

What is running

  • This page is served by nginx inside a container, listening on port 8080.
  • The container is not published to the host: only the Caddy edge is.
  • Caddy terminates TLS and proxies the request in over the stack network.

How to prove a redeploy

The build marker in the footer is the byte that only exists in a given build. Change it, rebuild, redeploy, then fetch the page and check the marker rather than trusting the pipeline log.
