catchError

A real GET /skilz that json-server answers with 404. What you return from catchError decides what the subscriber sees.

@for (entry of catchLog(); track $index) {
{{ entry }}
} @empty {
idle
}

retry

The first two attempts hit the 404 route, the third hits the real one. retry resubscribes with a 600 ms delay, so defer runs again and picks a new URL.

@for (entry of retryLog(); track $index) {
{{ entry }}
} @empty {
idle
}

catchWithFallback()

A custom operator: report the failure once, then keep the stream alive with a fallback value. Covered by a marble test in catch-with-fallback.spec.ts , run with npm test .

@for (entry of operatorLog(); track $index) {
{{ entry }}
} @empty {
idle
}
